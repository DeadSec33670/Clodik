Техническое задание

Мобильное приложение ArhoShop

Маркетплейс оригинальных кроссовок и одежды (поставка с Poizon). Версия документа 2.0 · основано на интерактивном прототипе.

1. О проекте

ArhoShop — магазин оригинальных кроссовок и уличной одежды. Есть рабочий сайт; задача — выпустить мобильное приложение с тем же функционалом. Готов интерактивный прототип всех экранов (прилагается) — эталон UI/UX.

В комплекте: Mobile App.dc.html (витрина — открыть двойным кликом), PhoneApp.dc.html (приложение, вся логика), app-products.js (демо-товары), support.js (рантайм прототипа). Все файлы держать вместе.

2. Технологии (рекомендация)

  • Клиент: React Native (iOS + Android из одной кодовой базы) либо PWA как быстрый старт.
  • Бэкенд: Supabase / Firebase (auth + БД + хранилище).
  • Оплата: ЮKassa / Tinkoff / CloudPayments.
  • Email: Resend / SendGrid / Unisender (восстановление пароля, подтверждение заказа).
  • Каталог: импорт и синхронизация данных Poizon.

4. Навигация

Нижний таб-бар, 4 раздела: Главная · Каталог · Корзина (со счётчиком) · Кабинет. Активная вкладка подсвечивается синим.

5. Экраны и функциональность

5.1 Главная

  • Промо-баннер «Новый дроп» с анимацией (парящая моделька) → ведёт в каталог.
  • Плитки категорий: Кроссовки, Одежда.
  • «Популярное сейчас» — горизонтальная лента, ранжирование по числу просмотров (кликов) товара.
  • Блок «Новинки» — сетка 2 в ряд.

5.2 Каталог

  • Строка поиска (по названию и бренду).
  • Чипы-фильтры по категориям: Все / Кроссовки / Одежда.
  • Сортировка выпадающим списком: Популярные / Сначала дешевле / Сначала дороже.
  • Сетка карточек 2 в ряд, кнопка «+» на карточке.

5.3 Карточка товара

  • Фото, бренд, название, цена.
  • Выбор размера. Добавить в корзину можно только после выбора размера.
  • Кнопка «📏 Таблица размеров» — разворачивает таблицу (обувь: EU/US/длина стопы; одежда: размер/грудь/длина).
  • Текст гарантий: «Проверка подлинности, доставка по всей стране. Возврат 14 дней.»
  • Кнопка «Добавить в корзину».

5.4 Быстрое добавление

  • Кнопка «+» на карточке открывает нижний шит с выбором размера (не добавляет сразу). Добавление — после выбора размера.

5.5 Корзина и оформление

  • Список товаров: фото, бренд, название, размер, изменение количества (+/−), удаление.
  • Итог: сумма товаров, доставка, итого.
  • Форма: Имя, Телефон (маска +7, 11 цифр), Город — все обязательны. Если пользователь вошёл — имя и телефон подставляются автоматически.
  • Выбор способа доставки: Курьером до двери / Пункт выдачи / Почтой России.
  • Экран успеха: номер заказа + начисленные бонусы.

5.6 Личный кабинет и аутентификация

  • Вход: телефон + пароль (с «Показать/Скрыть»). Только для существующего аккаунта; неверный пароль — ошибка.
  • Регистрация: Имя, Телефон, Пароль (под телефоном, мин. 6 симв., с «Показать/Скрыть»), Email — все обязательны.
  • Уникальность: один телефон = один аккаунт, одна почта = один аккаунт.
  • «Забыли пароль?»: ввод привязанного email → отправка пароля на почту.
  • Дашборд: карточка уровня лояльности с прогресс-баром, баланс бонусов, сумма покупок, список уровней, история заказов.

6. Программа лояльности

Бонусы начисляются с каждой покупки по ставке текущего уровня. 1 бонус = 1 ₽. Уровень — по сумме всех покупок; кэшбэк по уровню на момент покупки.

УровеньПорог (сумма покупок)Кэшбэк
Без уровнядо 50 000 ₽0%
🥉 Бронзаот 50 000 ₽1%
🥈 Сереброот 100 000 ₽2%
🥇 Золотоот 250 000 ₽3,5%
💎 Платинаот 500 000 ₽5%

7. Модель данных (минимум)

  • User: id, name, phone (уникальный), email (уникальный), passwordHash, createdAt.
  • Loyalty: userId, spent, bonuses, tier.
  • Order: id (номер), userId, items[{productId, size, qty, price}], total, delivery, status, earnedBonuses, createdAt.
  • Product: id, name, brand, category, subcategory, price, sizes[], images[], sizeChart.

8. Бизнес-правила (повторить точно)

  1. «Популярное сейчас» сортируется по числу просмотров товара.
  2. Нельзя добавить товар в корзину без выбора размера.
  3. Все поля регистрации и оформления обязательны; телефон — 11 цифр, email — по формату, пароль — мин. 6 символов.
  4. Один телефон = один аккаунт; одна почта = один аккаунт.
  5. Кэшбэк рассчитывается по уровню на момент покупки.
