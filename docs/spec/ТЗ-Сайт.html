Техническое задание

Сайт ArhoShop

Интернет-магазин оригинальных кроссовок и уличной одежды (поставка с Poizon). Версия документа 1.0 · основано на готовом рабочем прототипе index.html.

1. О проекте

ArhoShop — онлайн-магазин оригинальных кроссовок и одежды. Готов полнофункциональный фронтенд-прототип (одностраничное приложение, файл index.html + база товаров products.js): каталог, корзина, оформление заказа, личный кабинет с программой лояльности, анимации. Задача — довести до боевого продакшена: подключить бэкенд, оплату, реальную почту и каталог.

В комплекте: index.html (весь сайт и логика), products.js (каталог товаров, ~15 МБ). Файлы держать вместе в одной папке; точка входа — index.html.

2. Технологии

  • Фронтенд: готов как статический HTML/CSS/JS (SPA-навигация без перезагрузки). Можно оставить как есть или перенести на React/Vue при доработке.
  • Бэкенд: Supabase / Firebase / собственный API (Node, Python) — для аккаунтов, заказов, лояльности.
  • База данных: PostgreSQL / аналог.
  • Оплата: ЮKassa / Tinkoff / CloudPayments.
  • Email: Resend / SendGrid / Unisender (регистрация, восстановление пароля, подтверждение заказа).
  • Каталог: импорт и периодическая синхронизация данных Poizon.

4. Структура и экраны

4.1 Шапка (на всех страницах)

  • Логотип ArhoShop, навигация: Главная, Каталог, Кабинет, Контакты.
  • Кнопка «Кабинет» (имя пользователя, если вошёл) и «Корзина» со счётчиком.
  • Адаптив: на мобильном — бургер-меню.

4.2 Главная

  • Герой: крупный заголовок «Шаг, который заметят», вращающаяся по орбите витрина товаров (очки/футболка/кроссовок) с параллаксом от курсора, свечение за курсором, CTA в каталог.
  • Плитки категорий.
  • «Популярное сейчас» — карусель, ранжирование по числу кликов/просмотров товара (передняя карточка реагирует наклоном на курсор; стрелки с защитой от частых нажатий). Только обувь и аксессуары; одежда не показывается.
  • Блоки преимуществ, новинки.

4.3 Каталог

  • Сетка карточек (4 в ряд на десктопе), 3D-наклон карточки за курсором.
  • Поиск по названию/бренду.
  • Фильтры: категории (Кроссовки / Одежда / Аксессуары), бренды, размеры, диапазон цен; сортировка.
  • Категория «Одежда»: нижнее бельё показывается в самом конце списка.

4.4 Карточка товара (модалка)

  • Открытие через scale + размытие фона; крупное окно.
  • Галерея фото; зум по кнопке «Увеличить» — изображение приближается к точке под курсором.
  • Выбор размера; кнопка «📏 Размерная сетка» — разворачивает таблицу (EU/US/мм для обуви).
  • Добавление в корзину.

4.5 Корзина и оформление

  • Список товаров, изменение количества, удаление, итог.
  • Форма: Имя, Телефон (маска +7, только цифры, проверка на 11 цифр), Город — все обязательны.
  • Если пользователь авторизован — имя и телефон подставляются из профиля.
  • Экран успеха: номер заказа + начисленные бонусы лояльности.

4.6 Личный кабинет и аутентификация

  • Вход: телефон + пароль. Вход только для существующего аккаунта; неверный пароль — ошибка.
  • Регистрация: Имя, Телефон, Пароль (под телефоном, мин. 6 симв.), Email — все обязательны. У полей пароля — «Показать/Скрыть».
  • Уникальность: один телефон = один аккаунт, одна почта = один аккаунт.
  • «Забыли пароль?»: ввод привязанного email → отправка пароля на почту (нужен email-сервис).
  • Профиль: редактирование имени/телефона/email; смена пароля (текущий → новый → повтор, с проверками).
  • Дашборд: карточка уровня лояльности с прогресс-баром, баланс бонусов, сумма покупок, список уровней, история заказов с начислениями.

5. Программа лояльности

Бонусы начисляются с каждой покупки по ставке текущего уровня. 1 бонус = 1 ₽. Уровень — по сумме всех покупок. Кэшбэк рассчитывается по уровню, действующему на момент покупки.

УровеньПорог (сумма покупок)Кэшбэк
Без уровнядо 50 000 ₽0%
🥉 Бронзаот 50 000 ₽1%
🥈 Сереброот 100 000 ₽2%
🥇 Золотоот 250 000 ₽3,5%
💎 Платинаот 500 000 ₽5%

6. Модель данных (минимум)

  • User: id, name, phone (уникальный), email (уникальный), passwordHash, createdAt.
  • Loyalty: userId, spent, bonuses, tier (вычисляется из spent).
  • Order: id (номер), userId, items[{productId, size, qty, price}], total, status, earnedBonuses, createdAt.
  • Product: id, name, brand, category, subcategory, price, sizes[], images[], sizeChart.

7. Бизнес-правила (повторить точно)

  1. «Популярное сейчас» сортируется по количеству просмотров (счётчик кликов по товару).
  2. Все товары привязаны к корректной категории и бренду (нормализация при импорте: обувь → Кроссовки, одежда → Одежда и т.д.).
  3. Нижнее бельё относится к «Одежде» и показывается последним.
  4. Телефон валидируется (только цифры, 11 знаков); email — по формату; пароль — минимум 6 символов.
  5. Один телефон = один аккаунт; одна почта = один аккаунт.
  6. Все поля регистрации и оформления заказа обязательны.
